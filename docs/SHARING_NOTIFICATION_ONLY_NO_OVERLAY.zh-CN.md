# ScreenSync — 删除跨应用停止浮条，只显示一条共享通知

- 未共享期间：长期授权只保留在 ScreenSync 内的设置开关，无待机通知或悬浮条。
- 正在共享：只显示一条“ScreenSync 正在共享屏幕”普通通知，含“停止共享”按钮。无跨应用浮条。
- 用户关闭普通通知权限：配对、WSS、自动联网/重连、长期共享授权设置仍然工作，但不会在无人察觉、没有停止入口的情况下开始或继续截图。共享途中禁用通知，则本次截图终止。
- 重新允许共享通知后，长期授权模式下配对设备可发起新的观看请求。
- 不创建新的系统通知类别或悬浮窗权限，不强迫用户开启普通通知权限才能运行软件。
- 设备重启/强停及 OEM 后台限制仍不能保证自动恢复联机/截图，需真机验证。
