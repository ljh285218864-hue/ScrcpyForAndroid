# 观看方 B — 被观看方 A 离线时的推送唤醒与重试

B 在用户点击“观看对方屏幕”且打开观看界面后发出普通 `watch_request`。WSS 中转回应 `PEER_OFFLINE` 时，不自动判断为配对失败：在 B 的 UI 前台一次性请求后端 `/v1/push/wake`，服务器使用当前配对身份检查目标设备后尝试 FCM **NORMAL** 数据消息。

B 仅在用户仍保持观看界面且限时 45 秒内重发 `watch_request`，每隔 3 秒尝试一次；关闭界面、离开页面或主动取消会停止重试。不会循环推送或无限唤醒。A 收到合法唤醒时只恢复已明确开启的 WSS 后台信令，A 的无障碍系统权限、共享状态停止入口与本次授权/长期授权仍受独立检查。没有 Firebase 配置、网络不通、缺少 Play 服务、OEM 限制、系统强行停止时允许失败并可按原方式手动打开 A 的软件。

默认的 GitHub APK 若未设置四项 `SCREENSYNC_FCM_*` GitHub Actions secret 会成功构建，但 FCM 功能禁用，需实际配置 Firebase + 私有服务器账号和部署后才可使用。
