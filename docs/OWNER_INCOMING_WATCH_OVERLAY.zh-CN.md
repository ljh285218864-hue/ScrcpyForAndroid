# 后台观看申请提示（不依赖普通通知）

用户明确开启“后台在线维护”且 Android 仍允许运行进程时，屏幕截图尚未开启的设备可能收到已配对设备的 WSS 观看申请。

无障碍服务已由本机持有人开启时，优先显示短时“配对手机申请观看 / 打开确认 / 稍后”浮条（最多90秒）。点击“打开确认”只会打开 ScreenSync 页面，观看必须由设备持有人在页面内再次点“允许本次屏幕共享”，然后才可启动 JPEG 截图和可见的“停止共享”浮条。浮条不是系统通知，不需要普通通知权限，也不是隐藏式自动授权。

如无障碍服务未开启，则尽力使用允许的普通通知；若无任何通知方式可用，观看申请不会自动变成被允许的截图。App 强行停止、进程被回收、Doze、省电策略冻结及关机期间均不能保证接收申请。
