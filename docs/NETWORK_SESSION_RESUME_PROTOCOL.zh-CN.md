# 60 秒网络切换续接协议（仅内存、仅已批准会话）

- WSS 断开时，服务器将已经批准的会话暂停最多 60 秒，不再立刻删除；未批准的观看申请仍立即作废。
- 断开的来源或观看端必须在原进程内携带同一 `session_id`，重新进行 WSS 认证后发送 `session_resume`。
- 服务器检查双方配对身份、会话仍在、原先已批准且恢复未超时；重新上线后通知两端 `session_resumed`。
- 恢复后来源设备必须重新发送当前已授权 JPEG 会话的 `video_setup`；在此之前媒体包仍被阻止。
- 一旦任何一方主动停止、解除配对、超过 60 秒、手机重启导致原始内存状态丢失，均不能续接旧截图会话。
- 客户端必须确认来源侧无障碍共享仍在运行且停止按钮可见；不可因为服务器存在旧会话而自动发起新截图。
- 此修改只是 GitHub 源码，需将新的 `media_relay.py` 安全部署到大阪 VPS 后才能在真实网络切换时生效。不得影响旧 VPN/3X-UI 服务。
