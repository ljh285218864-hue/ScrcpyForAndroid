# ScreenSync — 仅在实际共享时提示（无待机悬浮条）

本次更新保持两台手机已配对、A 本机持有人明确开启长期共享授权、无障碍 JPEG 和 WSS 中转。

## 仅保留共享时一条状态

1. **不共享**：不显示长期授权待机悬浮条、观看申请浮条或任何应用发出的待机/连接通知。长期共享授权只在软件内“关闭长期共享授权（当前已开启）”开关展示和撤销。
2. **共享中，普通通知允许**：仅在通知栏显示一条“ScreenSync 正在共享屏幕”，内含停止共享操作，不同时显示共享悬浮条。
3. **共享中，普通通知关闭**：不能依赖通知栏。改显示一个无障碍跨应用悬浮条，内有“正在共享/停止并关闭长期授权”操作。无法显示任何可见停止入口时不启动/停止截图。
4. **途中关闭通知**：先尝试创建共享停止浮条，成功后才继续截图；无法创建就停止，避免隐藏共享。打开通知权限不自动生成第二条通知。
5. 点击共享停止按钮会结束本轮视频，并撤销长期共享授权；在 App 内另有长期授权开关。
6. 来自 B 的普通观看请求不再发送独立的“配对手机申请观看”系统通知。A 若未开启长期授权，只能在 App 打开时确认请求。

## 技术边界
- 所有普通通知权限均不参与 App 启动、后台心跳和配对的前置检查。
- 重启后是否收到新的观看请求取决于 Android 无障碍服务/进程与 WSS 是否能够恢复；此功能不能强行唤醒被系统强停的 App。
- 长期授权始终只对最初的那组设备有效，解除配对/撤销后不再可自动观看。
- 只有实际开始截图才生成任何视觉提示，截图前必有来源端可见的停止入口。系统禁止截屏页面可能无法共享。
- 不能保证系统通知开关、设备安全提示、无障碍服务状态由第三方应用完全控制。
