# 软件内共享通知开关（系统权限绝对优先）

本机可独立将“共享通知（软件）”设置为开启或关闭，默认开启；该设置保存在本机，不修改 Android 通知权限和通知渠道。

**最终通知输出 = 软件内允许 AND Android 系统允许 AND 共享通知渠道允许。**

- 软件开启 + 系统允许：实际发送屏幕画面时只发布一条“ScreenSync 正在共享屏幕”通知，其中有停止按钮。
- 软件开启 + 系统禁止：保持软件开关为**开启**，但**绝不发布**通知，不使用悬浮条或其他通知补偿，亦不请求/修改系统权限。后台在线、配对、WSS 重连照常运行。无可见共享停止入口时，不开始/继续后台采集屏幕。
- 软件关闭 + 系统允许：不发布通知；正在共享的会话立刻停止截图，配对/网络仍运行。
- 软件关闭 + 系统禁止：不发布通知。
- “查看系统通知权限”按钮仅在用户明确点击后打开 Android 应用通知设置，不会主动请求授权弹窗。
- Android 的系统级安全提示不受普通应用通知开关控制，App 不予规避。
- A 手机长期共享授权只影响已配对设备的请求批准，不强制开启通知，不改变 Android 系统通知权限。
